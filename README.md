# 霧走 MUSOU ― Prototype Racing

プロトタイプカー(ル・マンなどを走る耐久レース用の車)を操る **3DCG レースゲーム** です。

- **遊び方**:`index.html` をダブルクリック(Chrome / Edge / Safari)。Render で公開した場合は `https://(あなたのURL)/` で開けます
- **操作**:キーボード。↑/W アクセル、↓/S ブレーキ、←→/A D ハンドル、E/Q シフト(MT時)、Space ブースト、C カメラ、T テレメトリー、H 表示切りかえ、R コース復帰、Esc ポーズ
- **モード**:タイムアタック(ゴーストつき)/ レース(ライバル0〜7台、周回数・強さを選べる)

## マシン(実車がモチーフの架空の車)

| 名前 | モチーフ | 特徴 | メーター |
|---|---|---|---|
| KESTREL 962C | Porsche 962C(1986) | 水平対向6気筒ツインターボ。ターボの遅れ(ラグ)がある | 白い文字盤の針メーター |
| RV-4R 787 | Mazda 787B(1991) | 4ローター。9000回転まで回る甲高い音 | 緑と琥珀の LED バーグラフ |
| AURORA 919H | Porsche 919 Hybrid(2017) | V4ターボ+前輪モーターの4輪駆動。最速 | ハンドルの液晶+シフトライト |
| SOLSTICE 040 | LMH ハイパーカー(GR010 / 499P 世代) | V6ツインターボ+前輪モーター(160km/h から) | 弧を描くセグメント式タコメーター |

## しくみ(かんたんに)

- **3D の絵**:three.js(3D を描くための有名な無料ライブラリ)を `js/lib/` に同梱。ネットにつながっていなくても動きます
- **画像・音声ファイルは使っていません**。車体の塗装・アスファルト・木などの模様はキャンバスに描いて作り、エンジン音は「排気の1発1発の波形」を合成して作っています
- **車の動き**:タイヤ4本それぞれの荷重(重さのかかり方)・すべり角・摩擦円(タテとヨコの力の合計に上限がある、というタイヤの性質)、空気抵抗とダウンフォース(速いほど車が路面に押しつけられる力)、ターボのラグ、ハイブリッドの充電と放出を、1秒に120回計算しています
- キーボードでも走りやすいように、ステアリング補助・TCS(空転防止)・ABS(ロック防止)・姿勢制御があります(設定で切れます)

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/race.css` | 見た目(霧の白・淡い青+赤) |
| `js/data.js` | マシンとコースの数値(パワー・重さ・ギア比・コースの形など) |
| `js/track.js` | コースの形を計算(縁石・壁の位置・走行ライン・目標速度) |
| `js/physics.js` | 車の動き(タイヤ・空力・エンジン・ギア・運転補助) |
| `js/ai.js` | ライバル車の運転 |
| `js/carmodel.js` | 車の3Dモデルをその場で組み立てる |
| `js/world.js` | コースの3D世界(空・霧・地形・木・観客席・看板・煙・火花) |
| `js/textures.js` | 模様(塗装・路面・縁石など)をキャンバスに描く |
| `js/audio.js` | エンジン音・タイヤ・風・効果音・メニュー音楽を合成 |
| `js/hud.js` | メーター(4種類)・テレメトリー・ミニマップ |
| `js/main.js` | 全体の進行(メニュー・レース・カメラ・計測・結果) |

## 公開する(Render の静的サイト)
1. Render で「New +」→「Blueprint」を選び、このリポジトリを選ぶ(`render.yaml` が読みこまれます)
2. 「Apply」を押すと、数分で URL ができます(Build Command は空欄、Publish Directory は `.`)
